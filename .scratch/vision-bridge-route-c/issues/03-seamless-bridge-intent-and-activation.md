# 03 — Seamless 桥 + 意图提取 + 自动激活

**What to build:** vision-bridge 独有的无缝能力在新架构落地：纯文本会话粘贴截图自动落盘并注入路径与意图、读图被拦截时只给两行指路、bash 出图自动提示，且这些触发都会按 Agent 自动激活全部已实现工具。完成后可端到端走通「用户粘贴 → 工具自动出现 → 定位 → 裁剪」。

**Blocked by:** 02 — 核心工具主干道：远程三件套 + 本地三件套 + 产物管线

**Status:** ready-for-agent

## 会话上下文（开工前必读）

- 共享架构上下文：`.scratch/vision-bridge-route-c/CONTEXT.md`；本票实现第 3 节里的 seamless 层与 intent 层，并把 01 票的激活机制接上三个自动触发入口。
- **02 票已交付**：`vision_glance/ground/detect/crop/pixel_diff/dominant_colors` 六个工具、远程凭据管线、产物管线、假上游集成测试。本票不新增视觉算法，只做桥接与激活。
- **旧版可对照**：旧单文件插件里已有三条钩子的行为（粘贴落地、read 拦截、bash 出图检测），本票迁移其语义，但把全局状态改成按会话隔离，并按本文件规则重做 intent 与提示文案。
- **冻结的状态规则（状态机）**：

```text
未激活 Agent：上下文只有引导工具（vision_activate），没有任何执行工具
激活条件（任一命中）：
  ① 本 Agent 会话内发生粘贴落地 / read 图片被拦截 / bash 出图被检测
  ② 本 Agent 成功调用 vision_activate
  ③ 本 Agent 经 skill 工具加载了本插件打包的 vision-bridge skill（以返回内容标记判定）
激活后：执行工具注册到该 Agent；引导工具对该 Agent 隐藏
会话恢复：凭会话持久事件里的激活证据重新 attach；Agent 结束/插件卸载即回收
视觉模型会话：整套 seamless 钩子与激活都不触发
```

- **intent 提取规则（冻结）**：
  - 粘贴图片：只取**同一条用户消息**里的非图片文本作为 hint；没有伴生文本就无 hint，禁止借用更早上下文。
  - bash 出图自动描述：优先取**助手最后一个段落**的文本/推理（最后一段才说清要看什么），否则回退到最新一条真实用户请求。
  - 过滤注入内容：system-reminder、AGENTS.md、工具结果等不算用户/助手意图。
  - hint 一律截尾 500 字符，交给 02 票的视觉 prompt。
- **粘贴落盘规则（冻结）**：纯文本模型会话的 image block → 读附件字节 → 内容哈希命名 → 写入工作区固定输入目录（持久，不用系统临时目录）；同内容不重复落盘；消息里 image block 替换为「路径 + 同条消息意图文本（若有）」；落盘失败时替换为明确失败提示而不是假路径。
- **read/read_image 拦截规则（冻结）**：目标图片路径 + 当前模型不支持图片 → deny；deny reason 只写两行（“读不了图片”+“用 vision_glance/vision_ground”）并触发激活；完整明眼人协议只存在于 skill 内容，不随每次拦截重复注入。
- **bash 出图检测规则（冻结）**：检测 bash 命令/输出里的图片路径并确认文件存在；默认只注入「路径 + 建议工具」；自动描述默认关闭，开启时最多处理前 2 张、携带当前意图、受整操作超时约束、失败不阻断原结果。
- **能力检测规则（冻结）**：按 Agent 真实 provider/model 判断是否原生支持图片；成功结果正缓存；失败结果带 TTL，不永久缓存 false；settings/adapters 变更时失效。
- **旧版协议三处手抄问题**：本票交付后协议只有 skill 单一来源 + 视觉 prompt 单源，deny reason 不再含全文。
- **不做的事**：trace/extract/long_ocr/html_screenshot（04 票）；配置热更新、卸载清理完整版（05 票）；任何 UI 与发布。

## 验收标准

- [ ] 纯文本模型会话粘贴的图片块被替换为持久工作区路径 + 同条消息提取的意图文本；视觉模型会话整条链路不改动
- [ ] 粘贴图片按内容哈希去重落盘；没有伴生文本时只注入路径，不借用更早会话内容编造意图
- [ ] 粘贴触发后只激活当前 Agent 的工具与协议说明，其他会话不受影响；会话恢复后能凭持久证据重新激活
- [ ] read / read_image 对图片文件被拦截时，deny 只给两行指路；完整协议只出现在 skill 或激活后的说明里，不随每次拦截重复注入
- [ ] bash 产出图片后自动注入「路径 + 建议使用哪个工具」；自动描述默认关闭，开启时只处理前两张、使用当前意图、受操作超时约束
- [ ] 模型是否原生支持图片的判断按 Agent 解析，成功结果正缓存、失败结果带过期时间，不会一次失败永久误判
- [ ] 桥接状态按会话隔离（不设全局开关）；一个会话的触发不会给其他会话注入协议段
- [ ] headless e2e 覆盖完整链路：文本模型粘贴截图 → 工具自动激活 → `vision_ground` → `vision_crop`，并验证 read 拦截行为
